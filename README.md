# Non-Hermitian Quantum Adiabatic Algorithm

This repository will host the data and source code supporting the manuscript **“Non-Hermitian Quantum Adiabatic Algorithm”** by Zi-Bo Jin and Yi Zhang.

The data and source code are currently being curated and will be made openly available in this repository once curation is complete.

For access to the supporting materials during the curation period, please contact the authors.

## Repository structure

- `code/` — source code supporting the calculations and numerical results in the manuscript.
- `data/` — data supporting the figures and numerical results in the manuscript.

The contents of these directories will be added as curation is completed.
